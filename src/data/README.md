# Financial Horizon

Добро пожаловать в репозиторий проекта **Financial Horizon**.

## 📋 О проекте

**Financial Horizon** — это веб-приложение финансовой тематики, разработанное с целью повышения финансовой грамотности и удобного управления личными финансами. Главной особенностью интерфейса является геймификация процесса через использование интерактивных помощников.

### Интерактивные маскоты
Приложение сопровождает пользователя с помощью персонажей, которые дают подсказки и делают интерфейс более живым:
*   **Лис** (`fox`) — дружелюбный и активный помощник.
*   **Скрудж** (`scrudge`) — опытный наставник, символизирующий мудрость и бережливость.

## 🛠 Технологический стек

Проект использует современные инструменты веб-разработки для обеспечения качества кода и удобства поддержки:

### Core
-   **TypeScript**: Основной язык разработки. Строгая типизация позволяет описывать интерфейсы данных и избегать ошибок во время выполнения.

### UI & Styling
-   **Tailwind CSS**: Используется для стилизации компонентов.
    -   Применяется подход Utility-First.
    -   Активно используются произвольные значения (JIT mode), например `pl-[0]`, для точной настройки отступов изображений маскотов.
    -   Классы компонуются прямо в конфигурационных файлах данных.

### Accessibility (a11y)
-   **axe-core**: Интегрированная библиотека для тестирования доступности.
    -   Проект настроен на поддержку русского языка (локаль `ru`), что позволяет проводить валидацию интерфейса согласно правилам WCAG с понятными описаниями ошибок на русском (проверка контрастности, ARIA-атрибутов и семантики).

## 📁 Структура данных

Конфигурация приложения отделена от логики отображения.

### Конфигурация маскотов
Файл: `src/data/mascotsData.ts`

Этот файл служит источником данных для рендеринга персонажей. Он экспортирует массив объектов, где каждый элемент содержит:
-   `id`: Уникальный идентификатор (например, `"fox"`, `"scrudge"`).
-   `name`: Имя персонажа для отображения.
-   `path`: Путь к графическому ассету.
-   `className`: Набор CSS-классов Tailwind для индивидуальной коррекции отображения конкретного изображения.

## 🚀 Установка и запуск

### Предварительные требования

- Node.js
- npm или yarn

### Инструкция по установке

1.  **Установите зависимости:**

```bash
npm install
# или
yarn install
```

### Запуск в режиме разработки

```bash
npm run dev
# или
yarn dev
```
